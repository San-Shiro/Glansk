# Dev Log: 2026-09-19 - v0.1.1-alpha Proof-of-Concept Release

## Summary
Official migration from the initial experimental prototype ("LiteDash") to the public **Glansk** repository (`v0.1.1-alpha`).

## Key Milestones Achieved
1. **Public Repository Linking**:
   - Initialized Git on branch `main` linked to `https://github.com/San-Shiro/Glansk.git`.
2. **Industry-Standard Monorepo Architecture**:
   - Split codebase into `apps/server`, `apps/studio`, `packages/widget-sdk`, and `packages/shared`.
   - Unified workspace configuration with Bun package manager.
3. **Comprehensive Rebranding**:
   - Renamed all occurrences of LiteDash to Glansk across code, CLI binaries (`glansk-widget`), MIME types (`text/glansk-widget`), environment variables (`GLANSK_*`), and UI banners.
4. **Single Source of Truth Versioning**:
   - Established `packages/shared/src/version.ts` and automated CLI tool `scripts/bump-version.ts`.
5. **Licensing**:
   - Adopted Apache License 2.0 with full trademark and patent protection.
6. **Testing & Quality Assurance**:
   - 266 backend integration and unit tests passing with zero failures.
   - Playwright end-to-end suite verifying canvas drag-and-drop, multi-selection, grouping, and context menus.
