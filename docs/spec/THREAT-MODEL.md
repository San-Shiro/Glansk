# Threat model

Sensitive APIs require bearer authentication and explicit grants. Pairing codes expire, are single use, and issue least-privilege runtime sessions. Revocation denies reconnect. Cross-origin mutation, oversized input, quota excess, path traversal, missing hashes, unsigned production packages, invalid signatures, untrusted keys, unauthorized pins, and reset replay are denied and audited.

Widget code is untrusted. CSP denies object/plugin execution and framing of the admin, while packages remain capability constrained. All four packaged SDK widgets stay in `allow-scripts` iframes without `allow-same-origin`; the bridge rejects non-opaque origins, wrong source windows, wrong runtime-derived identities, wrong per-frame nonces, unknown message types, malformed fields, and messages over 16 KiB. Server adapters enforce exact package/widget/instance/channel tuples and a narrow command allowlist; command payload schemas and correlation IDs are checked. Widgets receive no credentials, direct broker/device access, storage authority, or network capability. Subscription teardown removes host tracking, preventing delivery after lifecycle cleanup. Signature validation authenticates a manifest and hashes; it does not make widget code safe. Development unsigned mode is documented and must not be enabled in production. The memory device provider verifies broker logic only and is not production GPIO or electrical-security evidence.

Carousel media is package-local and fail-closed: 1–32 paths, 12 KiB configuration, `assets/` confinement, raster extension allowlist, 256 KiB/file and 2 MiB/package policy. Traversal (including encoded), absolute/arbitrary schemes, data/blob, queries/fragments, SVG and GIF are denied. CSP keeps `connect-src 'none'` and permits only same-host packaged image loads in the opaque iframe. Lifecycle messages retain exact source/origin/runtime identity/nonce binding.

Residual validation: target-host load/performance, service-manager restart, real signing-key custody, physical Pi Zero 2 W carousel PSS/CPU measurement, and physical GPIO electrical tests (categorically excluded).
